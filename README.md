## Cómo trabajo
1. Context-first: leo contexto del repo + reglas del proyecto antes de tocar código.
2. Reuse gate: primero reutilizar, después crear.
3. Calidad obligatoria: build, lint, tests y revisión antes de merge.
4. Seguridad por defecto: no secrets hardcodeados, mínimos privilegios, trazabilidad.
